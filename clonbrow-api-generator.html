What the scan found
All 262 HTML files are inventoried. Two are files from the existing packaged Chromium app, leaving 260 user-facing prototype pages. Of those, 175 are lab, simulation, visualization or game candidates for embedding, 82 are other interactive pages, and 3 are informational pages. Page routes serve each prototype, but embedded JavaScript does not become a REST operation automatically. Eleven text utilities from main.html have direct API implementations. A further 21 HTML pages call external APIs, mostly Wikipedia plus geolocation and project-specific calls; those dependencies remain in the pages and are not rehosted. Flashcards are a new persistent API feature because the source collection has no flashcard backend.

  headers: { 'Content-Type': 'application/json' },

}).then(r => r.json());
