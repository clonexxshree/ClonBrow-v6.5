# ClonBrow Protected Player (prototype package)

## Open it

1. Extract `clonbrow-protected-player.zip`.
2. Open `clonbrow-protected-player/index.html` in a browser to view the portal.
3. Open `clonbrow-protected-player/documentation.html` for the workflow, API contract, watermark design, source-code limits, and deployment notes.

The portal buttons call the API routes described in the documentation. They require a deployed backend before health checks, node claims, uploads, downloads, and hosted playback can work.

## Package contents

- `index.html` — portal interface
- `documentation.html` — project and server documentation
- `clonbrow-logo.ico` — ClonBrow icon
- `README.md` — these instructions

This package does not include the 262 prototype source files or a live cloud backend. The proposed hosted API, database, private storage, player service, and deployment credentials are not present in this workspace.
