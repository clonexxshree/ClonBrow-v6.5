What the extension stores locally

The Clonbrow New Tab extension stores setup choices, pane session details, and HTML pages a user creates in Chrome extension local storage. These items are stored in the user's browser profile.

Optional theme services

Some bundled theme pages include account and synchronization features. When a user signs in or uses those features, the theme can send the account name and saved items—including tasks, flashcards, quizzes, notes, formulas, focus data, and other theme-specific records—to the Clonbrow service at clonexxshree.pythonanywhere.com. The data is used to provide the selected theme's sync and account features.
